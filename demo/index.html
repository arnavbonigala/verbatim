Verbatim

Lossless decode acceleration for AI coding agents. Verbatim drafts the text an agent is about to re-type from its own session (file views, diffs, escaped tool arguments), fills the gaps with a learned drafter, and has the model verify each draft in one forward pass. Every turn below was recorded on a fanless MacBook Air M3 (16 GB) running Qwen3-8B 4-bit on MLX, replaying real SWE-bench agent sessions.
